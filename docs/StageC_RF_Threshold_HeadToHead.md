# Stage C RF threshold head-to-head

Stage C compares RF accumulation in mm with rainfall STA/LTA R(t) at the threshold-derivation stage. Product 1 is paired with Product 3 for rainfall **preceding Constant TA**, and Product 2 is paired with Product 4 for rainfall **preceding the Outbreak Threshold**.

All four products use the upper-tail `RF >= threshold` operational direction. Head-to-head comparisons use common paired weeks, so differences in AUC or point-threshold performance are not caused by one representation having more evaluable weeks. The adopted thresholds remain scope-specific: NCR rows use NCR-derived fixed thresholds, whereas Regional rows use pooled-17-region fixed thresholds.

Reported evidence includes paired AUC comparison, sensitivity, specificity, balanced accuracy, PPV, and false-alarm rate. Regional paired inference includes all 17 regions. Threshold-stability analyses use NCR LOYO and Regional LORO re-derivation. Stage C figures use horizontal, multi-line x-axis labels and explicitly identify the rainfall representation as preceding its leptospirosis anchor.
